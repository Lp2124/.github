# Arquitectura — Fase 1

Monorepo con backend Laravel API en `backend/` y frontend React/Vite/TypeScript en `frontend/`.

En Fase 1 solo se prepara la base técnica: Laravel, Sanctum, MySQL, CORS local, React, Vite, TypeScript y Tailwind. No se implementan todavía wallets, mesas, poker, blackjack, WebSockets ni panel admin.
